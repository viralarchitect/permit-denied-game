# Vertical slice

Proof the game exists. Not a trailer. Not the campaign.

## What it is

The current county lot: tank-steer dozer, 3–5 minute gauntlet, named buildings fall, rubble pins you, cruisers bounce, you win by wrecking the list or lose to heat / stuck / clock.

If that is not fun, stop. Do not add Town.

## Must prove

1. Weight: turning and pushing feel heavy.
2. Targeted smash: player can read the next building and commit.
3. Rubble matters: leftover mass changes the next line.
4. Threats stall, they do not delete the player on contact.
5. Fail state is readable (heat / pin / clock).

## Slice contents only

- 1 map (existing lot)
- 1 dozer
- 3–5 building types already in the lot
- Cruiser, blocker, excavator, garnish chopper
- Score + result sheet
- Procedural rects acceptable; PNGs optional

## Explicitly not in the slice

Towns, city, capitol, meta unlocks, attachments beyond blade, new engine, new resolution, story.

## Pass / fail

A stranger can finish or die in one sitting and say “I want another run.” If they say “I want a gun,” the slice failed the fantasy, not the feature list.
